# agents-doctor QA eval, 2026-11-26

## Method

Programmatic fact checks: expectations in `scenarios/*/expected.json` and `tests/integration/expected/*/expected.json` are locked before the run; the runner builds each fixture, runs the deterministic scanner and compares the actual JSON to the expectations. The LLM layer of the skill is not covered by this evaluation. Asymmetry: FAIL proves a defect, PASS only means "not refuted in this run".
